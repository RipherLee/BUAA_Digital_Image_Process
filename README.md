# 数字图像处理实验

北京航空航天大学《数字图像处理》课程实验代码。

## 实验一 图像文件读取与操作、图像连通域提取

| 文件 | 说明 |
| --- | --- |
| `Exp1.ipynb` | 实验一全部代码及运行结果：图像读写、翻转/旋转/缩放、灰度化与灰度反转、二值化，以及两种连通域标记算法 |
| `ConnectedComponentLabeling.py` | 种子填充法与基于并查集的两遍扫描法的独立实现 |
| `helloworld_opencv.py` | OpenCV 环境自检：生成一张图像并存盘 |
| `Exp1_figs/` | 实验用的原图与各步骤输出的结果图 |

连通域标记部分用两种方法实现：种子填充法（显式栈，避免递归深度受限）和基于并查集的两遍扫描法（第一遍打临时标号并记录等价关系，第二遍用并查集合并后回填），二者结果一致，并与 `cv.connectedComponentsWithStats()` 的结果做过核对。

## 实验二 图像灰度变换与直方图均衡

| 文件 | 说明 |
| --- | --- |
| `Exp2.ipynb` | 实验二全部代码及运行结果：固定阈值二值化、线性对比度变换、手动实现直方图均衡、两种白平衡算法 |
| `Exp2_figs/` | 各实验输出的结果图（原图与处理后图像拼接而成的大图） |
| `testimgs/` | 实验用的测试图像，白平衡图像在 `testimgs/whiteBalance/` 下 |

四个子实验均手动实现变换本身，不使用 `cv.threshold()`、`cv.equalizeHist()` 等现成函数：

1. **阈值化**：比较运算得到布尔掩膜，再用 `np.where()` 映射为 255/0，阈值取 50、100、200；
2. **对比度变换**：`s = alpha * r + beta`，取 `beta = 0`，`alpha = 0.5` 降低对比度、`1.5` 提高对比度；
3. **直方图均衡**：`np.bincount()` 统计直方图、`np.cumsum()` 求累积分布，归一化得到 LUT 后一次性映射整幅图，彩色图按 R、G、B 三通道分别均衡再合并；
4. **白平衡**：灰度世界法（令三通道均值趋于同一个 $K$）与完美反射法（以 $R+G+B$ 最大的前 10% 像素为白点）。

实验要求中的“将原图与处理后的图像拷贝至大图像”由 notebook 里的 `concat()` 完成：统一通道数与尺寸后拼接，并可用 `cv.putText()` 在图上标注标题（该函数不支持中文，故标题用英文）。

> 说明：`Exp2_figs/` 中的结果图已经由 notebook 直接生成并入库，无需重新运行即可查看。

## 运行环境

- conda 虚拟环境 + JupyterLab
- Python 3.11.16、NumPy 2.4.6、OpenCV 4.14.0（`opencv-python`）

## 注意

代码里的图片路径写的是相对路径（如 `Exp1_figs/Lenna.jpg`、`testimgs/cameraman.tif`），**复现时请按本地的目录结构调整路径**，或在项目根目录下启动 JupyterLab，否则 `cv.imread()` 会读不到文件。

跑 `Exp2.ipynb` 前请先执行第一个单元格（其中 `os.makedirs("Exp2_figs", exist_ok=True)` 会建好结果图目录），否则 `cv.imwrite()` 会静默失败。
