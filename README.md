# 数字图像处理实验

北京航空航天大学《数字图像处理》课程实验代码。

## 实验一 图像文件读取与操作、图像连通域提取

| 文件 | 说明 |
| --- | --- |
| `Exp1.ipynb` | 实验一全部代码及运行结果：图像读写、翻转/旋转/缩放、灰度化与灰度反转、二值化，以及两种连通域标记算法 |
| `ConnectedComponentLabeling.py` | 种子填充法与基于并查集的两遍扫描法的独立实现 |
| `helloworld_opencv.py` | OpenCV 环境自检：生成一张图像并存盘 |
| `Exp1_figs/` | 实验用的原图与各步骤输出的结果图 |

连通域标记部分用两种方法实现：种子填充法（显式栈，避免递归深度受限）和基于并查集的两遍扫描法（第一遍打临时标号并记录等价关系，第二遍用并查集合并后回填），二者结果一致，并与 `cv.connectedComponentsWithStats()` 的结果做过核对。

## 运行环境

- conda 虚拟环境 + JupyterLab
- Python 3.11.16、NumPy 2.4.6、OpenCV 4.14.0（`opencv-python`）

## 注意

代码里的图片路径写的是相对路径（如 `Exp1_figs/Lenna.jpg`），**复现时请按本地的目录结构调整路径**，或在项目根目录下启动 JupyterLab，否则 `cv.imread()` 会读不到文件。
